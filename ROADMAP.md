# Agent Letterbox for Zellij roadmap

## v0.1 scope (local)

- Durable letters + reply-first protocol
- `letterbox zellij setup|run|register|unregister|status`
- Registry-first `adapters/zellij.sh` using `action write-chars --pane-id` + `action write --pane-id 13`
- Local Zellij only

## Not supported

- SSH/remote Zellij session packaging
- Plugins marketplace distribution as a dependency
- cmux/tmux/Herdr/desktop/webhook adapters in this tree

1. Dogfood with multi-agent Zellij layouts
